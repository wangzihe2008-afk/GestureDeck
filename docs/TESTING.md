# 验收与真实测试

## 已做的可重复检查

运行 `npm run typecheck`、`npm test` 和 `npm run build`。

自动化用例覆盖平移 / 大小 / 宽高比标准化、遮挡与画面边缘拒绝、静态姿势稳定性、单次捕捉、低频后台帧确认、离开姿势后重复触发、旧版 DTW 兼容、冲突检测、暂停、断帧、歧义、导入格式验证，以及模拟页面按钮 / 黑屏操作。

1.7.0 新增原生 VideoFrame 连续读取、每帧 close、pending read 取消和冻结检测。回归用例要求冷却期间放下手后连续识别五次，并向同一个模拟 Google Slides 标签派发五组方向键；不需要在演示中返回网站点击测试按钮。

开发用真实浏览器检查页使用合成视频帧。运行 `npm run build:connector` 并启动开发服务器，打开 `/tests/browser/background-camera.html`。点击运行后切到其他标签，12 秒后回来查看后台处理帧数和 FPS。此页使用本地模型，浏览器需要支持 WebGL。

1.8.0 的回归测试还会阻塞一次识别，确认摄像头继续给预览供帧、模型队列最多保留一个在处理的帧。实际设备上，启动 External Slides 后可以分别观察 Camera、Recognition 和 Preview FPS。

模拟页面不等于真实平台，生成序列不等于真人动作。请不要把测试通过数量写成识别成功率。

## 网站手动验收

| 检查         | 步骤                                       | 应有结果                                                                                     |
| ------------ | ------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 本地启动     | npm install → npm run dev                  | localhost:5173 显示工作空间                                                                  |
| PDF 样例     | 点击示例，连续切换多页                     | 页码正确，没有画布并发异常                                                                   |
| 上传 PDF     | 选择 / 拖入不同大小的 PDF                  | 保持比例，边界页不越界                                                                       |
| 黑屏和全屏   | B → B，点击全屏 → Esc                      | 黑屏可恢复，全屏可退出                                                                       |
| 摄像头拒绝   | 拒绝权限                                   | 说明如何授权，不显示假骨骼                                                                   |
| 质量检查     | 遮住手腕 / 离开画面                        | 阻止触发，提示重新入镜                                                                       |
| 姿势可用状态 | 让双肩、双肘、双手腕清晰入镜               | 显示 Pose readiness: Ready to use；不要求 100 分；即使置信度高，关节越界仍显示 Adjust camera |
| 异常骨骼坐标 | 摄像头刚启动、遮挡后重新入镜、快速切换页面 | 忽略瞬间的 NaN / Infinity 关键点；页面和按钮继续工作，不进入整页恢复界面                     |
| 单次捕捉     | 摆好一个姿势，保持约 0.7 秒                | 一次捕捉后可直接保存，不要求第二遍                                                           |
| 捕捉稳定性   | 捕捉期间持续移动手臂                       | 拒绝保存，提示保持一个姿势，不出现白屏                                                       |
| 冲突检查     | 为两个命令捕捉近乎相同姿势                 | 提醒冲突，要求换姿势                                                                         |
| 重复触发     | 触发后保持原姿势，再放下手重新摆出         | 保持时只触发一次；离开姿势两帧后可以再次触发                                                 |
| 持久化       | 保存姿势，刷新；导出再导入                 | 配置保留，重复 ID 更新                                                                       |
| 暂停         | Esc / 暂停按钮                             | 不再执行指令                                                                                 |

## 外部模式现场验收（必须在你的 Chrome 完成）

1. 加载 connector/dist，确认网站没有显示 Connector update required，然后刷新网站和目标演示。
2. 选择平台和 Editor 标签页，授权扩展摄像头，点击 Start camera check。
3. 后台预览必须显示正确画面；把双肩、双肘、双手腕放入镜头，等待 Ready for Present。遮住手腕时应显示具体提示，不能只显示含糊的 NO_POSE。
4. 点击 Present；不要返回 GestureDeck。姿势应在全屏中继续识别，连接器随后把目标状态改为 Slideshow。
5. 连续做五次“保持姿势、翻页、放下手约半秒”，始终停留在全屏。演示结束后检查 poses detected 与 slide commands sent 都已增加。
6. 如果没有连续翻页，记录演示结束后的 recognition FPS、识别次数、命令次数和当前状态，区分取帧、识别和按键发送哪一段没有继续。
7. 再切到其他无关网站，确认仍只控制指定演示标签页。
8. Alt + Shift + G 应暂停 / 恢复；扩展图标应完全停止并熄灭摄像头指示灯。
9. 关闭目标标签页或控制网站，确认摄像头关闭；将目标页导航到无关网站也应停止会话。
10. 重启 Chrome，不应自行启动摄像头。

本交付环境无法验证真实摄像头、用户演讲距离、OS 权限、登录后的 Canva / Google Slides 端到端行为。以上需要你本机现场验收。
